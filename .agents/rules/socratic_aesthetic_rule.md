# 苏格拉底交互与 DeepSeek 官方工程排版规范 (DeepSeek Socratic Aesthetic Rule)

适用范围：所有涉及 AI 交互式推导、教育考核类功能界面、Prompt 设计与代码实现。

## 1. 极致精炼与语言密度铁律 (Sacrifice Grammar for Concision)
1. **牺牲语法以换取极致精炼**：主动删去过渡修辞、连词与口语套话（严禁“你说得不对”、“这就是问题所在”、“那么问题来了”等口头禅）。
2. **直陈断层矛盾**：开篇直接以短句戳破直觉猜测与物理实现的本质断层，不寒暄、不讲故事。
3. **物理现实推进**：直接列出物理实体与状态流变（如 `ASCII 文本 -> 汇编 -> 二进制机器码 -> 内存映射`），命令结合行内后置注释。
4. **单点致命反诘**：末尾只抛出 1 个致命反诘追问，直戳核心实体或寄存器参数，逼迫学员自己推导出答案。
5. **严禁输出模板假标签**：绝对禁止打诸如 `🎯 认知断层`、`⚙️ 底层现实`、`⚡ 核心反诘` 这类机械八股文假标签。
6. **标点铁律**：中文引用必须使用全角双引号“……”（如“cpp 文件”），严禁使用英文半角双引号 "..."；技术名使用反引号（如 `hello.cpp`）。

## 2. 界面 Markdown 视觉标准 (DeepSeek 标杆)
1. **复刻 DeepSeek 官方 Blockquote**：
   - 严禁封闭式大圆角蓝色浮窗；
   - 统一采用左侧 `3.5px` 科技蓝纯色竖线（`border-left: 3.5px solid #165DFF`，底色 `#F8FAFC`，文字 `#475569`），极简专业。
2. **原生思考链折叠（Thinking Process）**：
   - 支持解析 `<think>...</think>`，渲染为可自由折叠/展开的 `💡 已深度思考` 扁平容器；
   - 思考中自动展开，思考完成默认收起。
3. **行内代码与排版**：
   - 黄金行高 `1.68`，正文深墨灰（`#1E293B`）；
   - 行内代码与标识符包裹在浅灰小药丸（`#F1F5F9`）中，等宽字体清晰锐利；
   - 底部集成轻量一键复制按钮。

## 3. 图标与品牌解耦
1. **导航操作用标准语义图标**：抽屉目录导航使用 `Icons.menu_rounded`，严禁拿 Logo 代替通用按钮。
2. **Logo 专属于品牌感知**：仅在 AI 消息头像和官方品牌标识位呈现。
