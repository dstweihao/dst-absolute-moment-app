# 绝对时刻 (Absolute Moment)

绝对时刻 (Absolute Moment) 是一个基于 Flutter 开发的现代 C++ 交互式推导与工程实践工作台。

项目结合苏格拉底式提问法与大语言模型（默认集成 DeepSeek V3 / R1），通过单点反诘与底层物理机理推导，引导学习者自主分析编译器行为、内存布局、汇编指令与操作系统调用，建立扎实的系统级编程直觉。

---

## 背景与设计初衷

在传统的 C++ 学习和开发过程中，开发者普遍面临以下三类现实痛点：

1. **认知断层与“假懂”陷阱**  
   阅读语法参考书或博客时容易产生掌握的错觉，但面对复杂的编译期错误、内存对齐开销、虚函数表多重继承布局或高并发竞态条件时，往往缺乏从源代码映射到底层硬件执行过程的连贯视角。

2. **生成式 AI 的“直接给答案”弊端**  
   常规大模型问答通常直接给出成套代码或原理结论。这种交互方式虽然便捷，却跳过了关键的分析、试错与推导环节，使用者往往“一看就会，一写就废”，难以建立独立排查系统级缺陷的工程能力。

3. **碎片化记录与资产流失**  
   使用网页端对话或零散笔记工具学习时，上下文容易丢失，缺乏按技术主线推进的递进式关卡与持久化沉淀机制。

本项目旨在构建一个专注、自洽的本地优先学习工作台，通过受控的 AI 交互协议与结构化知识路线，将学习过程转化为可复盘、可验证的工程推导链条。

## 核心设计与工程实现

### 1. 38 关现代 C++ 标准路线 (37 主线 + 1 综合关卡)

- **贴合现代语言标准**：以 C++23 / C++26 语言演进与现代工程实践为基准，覆盖概念约束（Concepts）、范围库（Ranges）、协程（Coroutines）、`std::expected`、`std::span`、`std::execution`、`jthread` 及 Linux `io_uring` 等关键特性。
- **单点聚焦原则**：每个关卡仅定义 1 个核心概念、1 个聚焦反诘与 1 条客观验收标准，避免多概念混杂，确保推导过程具备明确的物理边界与验收条件。
- **动态扩展能力**：支持指定本地工作目录。应用内的资源扫描器（ResourceScanner）会自动递归解析用户本地自定义节点的 YAML 配置，无缝挂载实际工程模块与专项 SOP 场景。

### 2. 苏格拉底式 AI 反诘引擎

- **多模型协议抽象**：提供统一的抽象客户端接口，内置 DeepSeek（OpenAI 兼容协议）、Claude（Anthropic 协议）实现，支持自由切换。
- **极度精炼提示词规范 (Extreme Concision)**：
  - 剔除客套问候、虚假标签与连词铺垫，提高信息密度。
  - 严格遵守“只追问、不给代码、不替用户下结论”的交互铁律。当使用者直觉猜测错误时，直接指出直觉与底层事实之间的矛盾，仅抛出 1 个致命反诘。
  - 标点与代码规范：文本引用统一使用全角中文双引号“……”，技术术语与文件名使用反引号。
- **深度思考与增量流式渲染**：
  - 核心通信采用 Server-Sent Events (SSE) 分帧协议，封装跨块 UTF-8 增量解码器，杜绝中文多字节截断乱码。
  - 原生支持 DeepSeek R1 `<think>` 思考过程解析，提供折叠收起与渐变渲染。

### 3. 防通胀掌握度评分系统 (Anti-Inflation Progression)

- **初始零分死锁**：当使用者回答“不知道”、“不会”、“报错”或输入字数小于等于 3 字符时，掌握度强制锁定为 0%，杜绝常规 AI 的同情分与起步分。
- **阶梯步进限制**：在未形成完整推导闭环前，单次有效对话的进度增量严格限制在 10% 以内，必须经历层层深挖才可提升。仅当全链路自洽证明成立时，系统方可确认 100% 掌握。
- **历史数据校准**：内置数据迁移算法，自动清洗历史遗留的虚假起步分，保证进度数据的真实性。

### 4. 关卡会话隔离与状态保留

- **独立持久化会话**：每个关卡绑定唯一的存储标识（`node_chat_<id>`），各关卡会话记录物理隔离，切换时不相互覆盖。
- **平滑导航切换**：无论从侧边栏切换回当前关卡，还是跨关卡查阅参考，应用自动保存当前状态并即时恢复上下文，不触发界面重置或输入丢失。

### 5. 本地优先 (Local-First) 与纯文本沉淀

- **格式透明**：所有学习推导记录与复盘打卡数据均以 Markdown + YAML FrontMatter 纯文本格式落盘。
- **双向兼容**：元数据（耗时、难度、掌握度）由 YAML 头部承载，便于程序检索；思考正文以标准 Markdown 章节记录，用户可直接使用本地文本编辑器（如 VS Code、Obsidian）打开和编辑。
- **云端同步集成**：内置标准 WebDAV 协议适配层，支持连接主流 WebDAV 网盘或自建云存储服务器，实现跨设备安全同步。

### 6. 安全防御与精准错误分类

- **敏感内容守护 (SensitiveContentGuard)**：本地前置识别情绪化与非技术用语，给出理性合规引导，规避无效交互。
- **精准故障排查**：捕获网络连接重置（TCP RST）并精准归类为合规拦截，明确区分网络超时、API Key 未配置、401 鉴权失效与上游配额耗尽，杜绝产生误导性报错。

## 课程体系大纲概览

标准课程路线按现代底层工程技术栈分为以下阶段：

| 阶段 | 核心模块 | 代表性知识点与验收标准 |
| :--- | :--- | :--- |
| **阶段 1：编译链接与底层突变** | 从源码到二进制的物理映射 | ASCII 文本、预处理展开、汇编转换、ELF 文件结构、text/data/bss 段分布、系统调用 `sys_exit` 与退出状态码传递 |
| **阶段 2：内存模型与对象生命周期** | 硬件内存与指针本质 | 虚拟地址空间、栈帧与寄存器传递、堆分配器机制、内存对齐与 Padding 计算、RAII 资源生命周期绑定 |
| **阶段 3：类型系统与面向对象机制** | 零成本抽象与多态开销 | 虚函数表指针（vptr）物理布局、多重继承偏移、RTTI 机制、移动语义与右值引用析构开销、完美转发 |
| **阶段 4：现代泛型与模板元编程** | 编译期计算与约束 | C++20 Concepts 约束匹配、编译期分发 `if constexpr`、变参模板展开、类型萃取与 `std::type_traits` 底层原理 |
| **阶段 5：现代并发与异步 I/O** | 现代硬件多核调度 | 缓存行与伪共享、内存序（acquire/release/relaxed）、无锁队列原理、`std::jthread` 协作式取消、协程帧布局与调度 |
| **阶段 6：系统级工程实践** | 工业级构建与调优 | CMakePresets 构建规范、SIMD 矢量化向量优化、Linux `io_uring` 高并发事件循环、动态链接符号解析与热重载 |

## 技术架构与目录结构

本项目严格遵循领域驱动设计与清晰架构（Clean Architecture）原则，使用 Riverpod 进行依赖注入与响应式状态管理：

```
lib/
├── core/                  # 全局设计规范：色彩系统、间距体系、排版样式、工具类
├── data/
│   ├── ai/                # AI 引擎通信层：客户端抽象、SSE 流式解析器、提示词工程
│   ├── credentials/       # 凭证加密持久化
│   ├── repositories/      # 仓储实现：路线管理、资源扫描、打卡记录落盘
│   ├── serialization/     # Markdown / YAML FrontMatter 序列化与反序列化
│   ├── storage/           # 本地文件存储抽象（平台区分 IO 与 Web）
│   ├── updates/           # 自动更新检测与分发模块
│   └── webdav/            # WebDAV 同步客户端与适配层
├── domain/
│   ├── enums/             # 领域枚举定义
│   └── models/            # 领域核心实体：Node、Checkin、AiSettings 等
├── features/
│   ├── ai_settings/       # 模型选择、API Key 配置与连接测试
│   ├── dashboard/         # 学习概况看板与统计图表
│   ├── learn/             # 核心学习交互页：流式会话气泡、即时评分
│   ├── onboarding/        # 新用户引导与环境初始化
│   ├── settings/          # 存储路径设置与多端同步配置
│   ├── sop/               # 结构化推导 SOP 流程与会话编排
│   ├── stats/             # 个人攻坚数据统计
│   └── tracks/            # 路线图列表与关卡详情视图
├── shared/                # 跨模块通用 Widget 组件库
├── app.dart               # 根 Widget 与全局主题配置
├── main.dart              # 应用执行入口
├── providers.dart         # Riverpod 全局状态流注入点
├── router.dart            # GoRouter 声明式路由与状态保留容器
└── shell.dart             # 主界面骨架侧边栏导航
```

## 快速上手

### 环境要求

- **Flutter SDK**：`>= 3.24.0`
- **Dart SDK**：`>= 3.5.0`
- **支持操作系统**：macOS (推荐)、Linux、Windows、Web 浏览器

### 1. 克隆代码与获取依赖

```bash
git clone https://github.com/dstweihao/dst-absolute-moment-app.git
cd dst-absolute-moment-app
flutter pub get
```

### 2. 运行单元与集成测试

确保本地环境正确无误：

```bash
flutter test
```

### 3. 本地启动应用

- **macOS 桌面端**：
  ```bash
  flutter run -d macos
  ```
- **Web 浏览器端**：
  ```bash
  flutter run -d chrome
  ```
- **Windows / Linux 端**：
  ```bash
  flutter run -d windows
  # 或
  flutter run -d linux
  ```

### 4. 配置 API Key

首次启动后，进入侧边栏的 **“设置” -> “AI 服务配置”**：
1. 服务商选择 **DeepSeek**（默认兼容官方 OpenAI 协议接口）。
2. 输入您的 DeepSeek API Key。
3. 选择预设模型：`deepseek-chat` 或具备深度推理能力的 `deepseek-reasoner`。
4. 点击“测试连接”，验证网络与密钥可用性。
