## 💡 「绝对时刻」能为你解决什么？

**「绝对时刻」不是另一个死板的刷题软件，也不是单纯的大模型聊天套壳。**  
它是一座为你量身打造的**现代化硬核自学终端**，像一位坐在你身边的严格技术导师，带你真正吃透 C++：

### 1. 🎯 38 关精炼主线：告别迷茫，像打游戏一样通关进阶
我们摒弃冗余的语法废话，将现代 C++ 的底层主线精炼萃取为 **38 个核心关卡**：
- **从最物理的硬件机制起步**：代码如何变成机器码？内存段怎么划分？指针和引用的底层汇编有什么差别？
- **攻克核心对象与内存模型**：RAII 资源生命周期、虚函数表与多重继承内存布局、右值引用与完美转发。
- **跨越到现代特性与高并发系统**：C++20 Concepts 约束、编译期计算 `if constexpr`、多核缓存行、无锁原子内存序到协程调度。

**一关只专注攻破一个核心概念**。打通一关点亮一关，进度一目了然，彻底终结东一榔头西一棒子的迷茫！

### 2. 🤖 绝不直接给答案的 AI 导师：带你一步步推导本质
普通 AI 是“喂饭”，而「绝对时刻」的 AI 导师（原生接入 DeepSeek V3、R1 深度思考模型与 Claude）是一位**极度严格的硬核教练**：
- **拒绝直接给代码**：当你提出疑问或提交推导时，它不会直接把答案塞到你嘴里，而是敏锐抓住你逻辑里的盲区，一步步追问引导。
- **逼你向底层追溯**：“这块内存在堆还是栈？”、“编译器在这里生成了什么指令？”。只有你自己的推导严丝合缝、证明自己真正理解了，系统才会结算 100% 掌握度。**在这里，你永远不可能靠蒙混过关假懂！**

### 3. 📂 数据 100% 属于你：纯本地优先，跨设备自由同步
- **不依赖第三方云端数据库**：你所有的每日打卡、推导笔记、关卡历史，全部以**纯文本 Markdown 文件**保存在你本地电脑的文件夹中。
- **多端无缝协同**：数据文件夹可直接设置在**坚果云、iCloud、OneDrive 或本地 Git 仓库**，在 Mac、Windows、手机或平板之间实时漫游同步。永远不怕封号断网，打造你一辈子带得走的个人技术沉淀。

### 4. 🍎 极简克制的 Apple HIG 设计：安静专注的心流体验
- **告别花哨模板与视觉干扰**：全面遵从 Apple 人机交互设计规范（HIG），纯净的分组卡片、极细发丝线排版、无弹窗广告、无浮躁营销。
- **打开即学**：开箱即用，流畅丝滑，让你将 100% 的精力投入在纯粹的思考与推导中。

## 🚀 3 步开启你的通关之旅

1. **输入你的 API Key**：
   - 打开 App 侧边栏的 **“设置”**，填入你的 DeepSeek API Key（支持一键查询官方实时账户余额，千次推导交互仅需几毛钱）。
2. **选择今日关卡**：
   - 在主线大纲中点击进入你当前要攻坚的知识点（如指针底层、RAII 或虚表模型）。
3. **与 AI 导师过招推导**：
   - 面对关卡提出的核心机制问题，输入你的推理分析；AI 导师会与你展开单点攻防。推导成立后点击完成，生成今日打卡沉淀到本地。

## 🛠 开发者本地运行与测试

如果你想参与贡献或自定义课程路线，欢迎在本地拉取代码运行：

```bash
# 1. 克隆代码仓库
git clone https://github.com/dstweihao/dst-absolute-moment-app.git
cd dst-absolute-moment-app

# 2. 拉取依赖
flutter pub get

# 3. 运行自动化测试套件（189/189 全绿通过保障）
flutter test

# 4. 本地启动
flutter run -d macos    # macOS 桌面端
flutter run -d chrome   # Chrome 网页版
flutter run -d windows  # Windows 桌面端
```
